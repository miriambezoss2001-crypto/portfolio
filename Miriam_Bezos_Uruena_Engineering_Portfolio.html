Reclaimer

Operating modes & preparation

The documented system includes No Mode, Maintenance, Cabin, Automatic and Program modes. Automatic operation requires prior program setup and all Local Control Stations in Remote.

  • Pile type and working zone
  • Start/end position memory
  • Boom initial height
  • PLC readiness check
  • Encoder-based position feedback
Travelling

Drive & feedback

The travelling system uses six drives across rigid and articulated sides. VFDs, motor brakes, position feedback and safety monitoring are integrated into the operating philosophy.

  • Forward / reverse
  • Speed control
  • Encoder position
  • Anti-crabbing monitoring
  • Travel and emergency limits

Control

Speed, position & PID

Travel speed can be adjusted from 0–100%. Boom position is managed by the PLC using encoder feedback. The documentation also describes a selectable manual/PID approach for travelling speed.

Safety

Alarms and interlocks

The manual distinguishes alarms requiring acknowledgement/reset from interlocks that prevent a function from activating. Devices include emergency stops, collision switches, limits, anti-crabbing, temperature and encoder-related protection.

Shiploader

Automatic conveyors

Start order arrives from the Main Control Room. Conveyors start downstream-to-upstream, one by one, advancing when the previous conveyor reaches full speed.

Shiploader

Controlled stop

On stop, conveyors stop upstream-to-downstream; the next step advances when the conveyor is empty.

Interfaces

Mechanical + automation

Drives, brakes, feedback, local/remote selection, safety logic, HMI status and start/stop orders must remain coordinated.

03 / FINAL DEGREE PROJECT · UNIVERSITY OF OVIEDO

Mode I Fracture & Delamination Behaviour of Adhesive Joints in Carbon/Epoxy Composites

Experimental research into the influence of high-humidity exposure on adhesive joints in carbon-fibre/epoxy composites, combining accelerated environmental ageing, mechanical testing, fracture mechanics and data analysis.

Material

Unidirectional carbon fibre/epoxy composite with structural adhesive joints.

Methods

Double Cantilever Beam testing. Data reduction via Modified Beam Theory, Compliance Calibration and Modified Compliance Calibration.

Analysis

Mode I fracture toughness GIC, crack-growth rate da/dN and adapted Paris-law analysis.
